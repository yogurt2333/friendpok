# 全角色对战试玩

双击《全角色对战.html》离线运行，保留 assets 文件夹。现有10位角色任意选择双方，包含镜像对战。秋秋采用最新弱电工造型。点击开始后自动完成整场；新开一局换种子，同局重播复现同样结算。

- HP100，随机先手，轮流行动；AI自动选技能。
- 普通技不能连续重复；自身完成两次行动后解锁大招，每场一次。眩晕跳过的行动不计入解锁。
- 单招共用命中、暴击和浮动判定；伤害浮动±5%，暴击10%概率、1.5倍。多段招式在对手HP归零后停止后续伤害。
- 减伤30%、增伤30%、命中降低20个百分点：对应的下一次攻击消耗，未命中也消耗，恢复不消耗，不叠加。眩晕跳过下一次行动。吸血按实际伤害50%向下取整，上限8、不过满血。
- 暂停、1/2/4/8倍速、跳过本招、重播、重开；后台/Escape暂停；本地保存及继续上次对战。
- 双方各2×2技能卡，标记当前招式和可用状态，显示大招解锁及战斗日志。
- 最多60次行动，按剩余血量决胜，同血量按种子抽签。没有加入属性克制。

这是10位角色的自动1v1实战版；16人左右半区瑞士轮、积分榜、加赛和手动操作仍未实现。原已验收的两人版与独立动作校验页保留。
