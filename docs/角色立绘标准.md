# 朋友对战 · 角色立绘标准 v1

生效日期：2026-10-28。

## 唯一基准

**以 `assets/mano-proportions.png` 中间标注「50%」的 Mano 为母版。**

不是左边 75%，也不是右边 25%。这里的 50% 是原对照方案的名称，不表示头占全高一半，也不表示把整张图缩小一半。

Mano 现有待机立绘、捡烟动作、扑飞动作和技能图保持不变。本次只修正通风橱待机立绘。以后新角色必须同时参考母版和本人照片，不能只凭「大头小身体」文字生成。

## 比例要求

量取站立姿势的头顶到鞋底，不计道具、侧马尾、帽饰和特效。

| 项目 | 目标 |
| --- | --- |
| 头顶到下巴 | 人物全高约 2/3，允许约 ±3 个百分点，以母版并排观感为准 |
| 下巴到鞋底 | 人物全高约 1/3；躯干短、腿短，不能画成长腿或高瘦人物 |
| 头部宽度 | 人物全高约 70%–80%；发型保留特点，但不靠蓬高头发增加角色身高 |
| 站姿 | 双脚着地，正脸可见，身体可略朝向对手 |
| 手脚与衣服 | 同等粗细的像素块，适度简化；保留衣服轮廓，不逐根画头发或衣褶 |

这是一份制作约束，不是对 AI 图片像素级精度的保证。比例是否通过，必须用同一显示尺度与 Mano 母版比对，不能只凭生成提示词或文件名认定通过。

## 画风与辨识度

- 粗黑阶梯轮廓，硬边像素，有限色板；每种材质通常 2–3 层明暗。
- 保留发型、发色、眼镜、穿搭和一个标志性道具。
- 脸部简化；人物特征以照片与明确要求为准。例如通风橱必须是黄色妹妹头、刘海遮眼、灰色衣裤、手持肉肠。
- 不添加写实光影、柔光、光晕、背景、地板、投影、文字、百分比标签或额外角色。

## 文件与页面显示

- 独立 RGBA 透明 PNG，一人一张；推荐正方形交付画布，全身不得裁断。
- 角色居中，头顶与鞋底保留少量透明边距，画布占比约 84%–90%。
- 素材用有版本号的文件保存；替换页面引用，不覆盖已通过的源图。
- 页面统一脚底基线，并以可见头部尺寸、可见全身高度比较，不以图片画布宽高比较。
- 保持宽高比。禁止为了对齐，把整个人横向拉宽或纵向拉长。
- 普通小道具不大于头部约 1/3；贝斯等大型乐器可横跨小身体，但不能撑长躯干、手臂和腿。大招里的夸张放大属于演出，不改变待机比例。
- 采用最近邻/`image-rendering: pixelated` 显示。当前 Mano 展示方式保持原样；其他角色向她对齐。

## 新角色通用提示词

> 参考图 A 为角色比例母版，只参考三版本对照图中间的 Mano 50% 版，忽略左边 75% 和右边 25%。参考图 B 为本人照片。生成一个独立、透明背景、全身、正面待机像素小人。严格匹配母版的大头短身体：头顶到下巴约占人物全高 2/3，下巴到鞋底约 1/3，短躯干、短腿、较宽的头部。保留本人【发型、发色、脸部特征、穿搭】及【常驻道具】。与母版使用一致的粗黑阶梯描边、粗细统一的方形像素、有限色板和 2–3 层明暗。头发不能画成高耸椭圆，衣服不能把躯干拉长。无文字、标签、背景、地板、投影、光晕、柔化边缘。只有一个完整人物，四周留透明边距。

## 每个新角色必须通过的检查

1. 与 Mano 并排，脚底对齐，整体观看距离相同。
2. 头部高度、宽度接近，人物全高相差原则上不超过约 5%；夸张发型按脸和下巴位置辅助校准。
3. 检查下巴到鞋底的长度；不能只把整个大角色缩小来掩盖内部比例差异。
4. 衣服和道具能认出来，头发没有密集细丝，透明背景没有黑底或光晕。
5. 放进对战页确认：人物不比另一方大一圈、不悬空、不踩出平台。
6. 用户视觉确认后才标记「已通过」。
