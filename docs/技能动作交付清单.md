# 全角色技能动作交付清单

10位已建角色，共40招。Mano、通风橱8招保持原已验收版本；其余8位32招为本轮统一待验收版本，其中剑玉摆锤初版已获认可。

## 打开方式

双击 全角色技能校验.html，选择角色后点击技能卡，或一键连播32招。无需网络或服务器。支持1/2/4/8倍速、暂停、重置、切换角色；切到后台或Escape暂停。

普通动作2.8秒、大招3秒；当前是固定命中、固定数值演出，不是新八位的正式战斗引擎。每招一张专属动作图，配合位移、旋转、命中特效、恢复提示、音波、控制提示组成演出。不是逐帧手绘骨骼动画。

## 特效来源与验证

命中星芒与音波复用本地 Warped Shooting Fx / ansimuz（CC0）；许可记录 assets/fx/warped-fx-license.txt。代码窗口、气泡、眩晕星星、状态指示通过Canvas/UI绘制。角色动作图用内置图像生成工具，保留原始待机图和历史稿。

检查：32招的脚本语法、非视觉DOM交互、伤害/回血最终值、暂停重置、8倍速完整连播；另检查全部素材存在及透明通道。程序检查不能代替用户对动作表现与画风的视觉验收。

构建：work/build-roster.py 将样式和脚本合入单HTML；图片与字体外置。可维护源文件在 outputs/assets/roster-*.js/css，模板在 work/roster-shell.html。

秋秋外观于2026-10-29更新：按新照片改为自然黑短发、小眼睛和自然鼻口，减少动漫感；待机与四招动作同步更新为v2，旧图保留，技能数值和演出节奏不变。
