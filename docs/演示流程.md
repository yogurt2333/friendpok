# 现场演示流程

## 开场前 5 分钟

1. 全屏浏览器（F11），缩放 100%。
2. 优先打开在线版：https://yogurt2333.github.io/friendpok/
3. 兜底：双击本地 `index.html`，确认旁边 `assets` 文件夹在（断网也能跑）。
4. 随手开一局，等所有立绘加载完，再点「新开一局」回到干净状态 —— 避免现场第一次加载卡图。

## 3 分钟脚本

| 时间 | 说什么 / 做什么 |
| --- | --- |
| 0:00 | 「把身边 12 个朋友做成了宝可梦式对战角色，每人一张像素立绘、四个技能。」 |
| 0:20 | 左右各选一位（推荐 秋秋 vs Mira：技能名最有梗，一个用贝斯一个用 CD 飞盘）。 |
| 0:40 | 点「开始对战」，速度切到 8 倍。讲规则三条：HP100 随机先手、普通技不能连用、自己动两次解锁大招每场一次。 |
| 1:30 | 打到一半点「暂停」，说明这是本地单文件、无服务器；再继续。 |
| 2:00 | 分出胜负后点「同局重播」：同一随机种子，技能、暴击、结算完全一致。 |
| 2:30 | 收尾：目前 10 位接入实战，小草莓和小月只有立绘；下一步是 16 人瑞士轮、积分榜和加赛。 |

## 现场可能踩的坑

- **对局太长**：小红 vs Fiona 这类会互相回血的组合可能打到 30+ 次行动，直接倍速 8x 或点「跳过本招」。想换一局就点「新开一局」，它会换种子。
- **对局秒结束**：同样点「新开一局」重抽，平均一场约 9 次行动，适合现场。
- **图片裂开**：`index.html` 和 `assets/` 必须同级，别单独拷走 HTML。
- **字体变细/发虚**：像素字体没加载，检查 `assets/fusion-pixel-12px-zh_hans.woff2`。
- **投影偏色**：页面是深绿灰底（#71888a）+ 米色字，投影用「标准/演示」模式，别用电影模式。
- **切窗口自动暂停**：这是设计行为，切回来点「▶ 继续」。

## 被问到时的回答

- **为什么没有属性克制、速度、防御？** 原型阶段只做数值和演出，先把角色和技能演对；克制留到下一版。
- **数值平衡吗？** 都是占位平衡初值，用 1000 场种子模拟验证过规则一致（回血上限、吸血、眩晕跳过、KO 提前终止），不代表最终平衡。
- **能手动选招吗？** 还没有，目前是 AI 自动打完整场，手动模式在待办里。
- **这些立绘怎么做？** 朋友本人提供照片 → 统一 50% 头身比例母版 → 像素化，每人再出四张技能图。
