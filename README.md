# 朋友对战

打开 `index.html` 开始十二人四轮瑞士轮；打开 `全角色对战.html` 自由对战。全部图片和音乐本地加载，支持离线。

## 实时赛事

点击“开始第1轮”，六场比赛依次播放，双方逐招动画、技能名、伤害和回血同步显示；每场播完才更新积分。支持暂停、1/2/4/8倍速、音乐/音效独立开关、音量调节。每轮结束手动开始下一轮。刷新后可继续本轮，尚未结束的一场从头播放。已结束的比赛可重播，重播不改变积分。赛事保存在当前浏览器中。

12位角色，每人四招。小草莓、小月各有四张独立透明技能动作图，已接入战斗，画面待用户最终验收。原立绘与历史动作图保留。

瑞士轮：4轮、每轮6场、胜1分负0分；优先同分、回溯配对避免重赛。胜场相同依次比较对手分、累计剩余HP、赛前种子抽签顺序。四轮第一名夺冠，不另设淘汰赛。

## 音频与美术

战斗音乐：8-Bit Battle Loop / Wolfgang_（Theodore Kerr），CC0。许可和来源见 `assets/audio/CREDITS.md`。音效为原创程序合成，出招、大招、命中、落空、回血和胜利使用不同声音，跟随实际结算时刻。浏览器若限制播放，点击“开启声音”。

新动作图位于 `assets/skills/xiaocaomei-*-v1.png` 与 `assets/skills/xiaoyue-*-v1.png`。生成说明见 `work/new-skill-art-prompts.md`；独立预览 `new-skills.html`。

## 开发

`npm ci` 安装测试依赖；`npm run build` 构建对战页；`npm test` 检查战斗规则、1000届赛事、离线DOM播放与逐场计分流程。

角色和战斗源码在 `assets/`；不要只修改生成的 `全角色对战.html`。本地静态预览可运行 `python -m http.server 8765 --bind 127.0.0.1`。
