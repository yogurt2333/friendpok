# 朋友对战
打开 index.html 开始十二人四轮瑞士轮；打开 全角色对战.html 自由对战。资源均本地加载，支持离线。

12 位角色、每人四招。小草莓和小月使用现有立绘配合各技能程序动画，尚待用户视觉验收；没有新增独立动作 PNG。历史素材保留。

瑞士轮：4轮、每轮6场、胜1分负0分；优先同分、回溯配对避免重赛。胜场相同依次比较对手分、累计剩余HP、赛前种子抽签顺序。四轮第一名夺冠，不另设淘汰赛。刷新保存进度，新建赛事清空本届积分。观看按钮回放对应战斗种子。

构建：python work/build-roster-battle.py
验证：node work/check-swiss.cjs
角色和战斗源码位于 assets/，不要只修改生成的全角色对战.html。
