# 朋友对战 · friendpok

把身边的朋友做成宝可梦式的对战角色：每人一张像素立绘、四个技能（三招 + 一个大招），选两位自动打一整场。
纯前端，一个 HTML 跑起来，不需要服务器、CDN 或安装依赖。

## 在线试玩

https://yogurt2333.github.io/friendpok/

## 本地离线跑

双击 `index.html`，保持同目录下的 `assets` 文件夹完整。图片、字体、脚本全部相对路径，断网也能演示。

- 左右各选一位角色（10 位可选，含镜像对战）。
- 点「开始对战」自动打完整场；「新开一局」换种子，「同局重播」用同一随机种子复现完全相同的结算。
- 支持暂停、1/2/4/8 倍速、跳过本招；切走页面或按 Esc 会暂停。
- 浏览器允许本地存储时会记住进度，刷新后可「继续上次对战」。

## 战斗规则

- 双方 100 HP，无属性克制；随机先手，轮流行动，AI 自动选招。
- 普通技不能连续重复使用；自己完成两次行动后解锁大招，每场一次。三连击算一次行动。
- 单招共用命中、暴击、浮动判定：伤害 ±5% 浮动，暴击率 10%、倍率 1.5。多段攻击在对手 HP 归零后停止后续伤害。
- 状态效果：减伤 30%、增伤 30%、命中降低 20 个百分点，各消耗一次攻击机会（未命中同样消耗，回血不消耗，不叠加）；眩晕跳过下一次行动；吸血按实际伤害 50% 向下取整，上限 8。
- 每场最多 60 次行动，达到上限按剩余血量决胜，同血量按种子抽签。
- 同一局先生成完整战斗记录，动画只消费记录 —— 加速、暂停、跳过都不改变结果。

## 文件结构

```
index.html              演示页（脚本样式内联，素材外置）
skills-preview.html     四招技能图 + 动作校验页
assets/
  characters/<角色>/    待机立绘、角色设定
  skills/               每人四招技能图
  fx/                   技能特效
  roster-*.js           战斗引擎 / 渲染 / 选人
  pixel-ui.css          像素风 UI 与 50% 立绘母版约束
docs/                   玩法说明、角色与技能确认表、立绘标准、技能交付清单
```
