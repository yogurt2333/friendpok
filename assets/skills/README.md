# Mano 技能动作样板

角色采用已确认的 Mano 50% 版为参考，使用内置 image_gen 生成独立透明 PNG。

- `mano-pick.png`：低头伸手捡电子烟。
- `mano-fly.png`：头朝右、身体近横向扑飞撞人。
- `mano-vape.png`：已确认的粉色果汁盒电子烟道具。

最终提示词约束：仅使用三比例参考图中间的 50% 角色；保留粉色低双马尾、深色发根、白色荷叶边裙、白袜黑鞋、大头短身体；粗黑像素轮廓、有限色板、透明背景。捡烟动作向右前倾伸手；扑飞动作头朝右、短腿向左、闭眼张嘴，不把撞击光效画进角色。

演出：0–300ms 掉烟，300–950ms 低头捡，950–1600ms 扑飞，1600–2050ms 撞击与伤害，2050–2800ms 归位。1× 总计 2.8 秒，速度控制影响虚拟时间，暂停不推进时间。固定伤害 24，仅供演出验证，非正式战斗引擎。

现成命中特效：ansimuz / Warped Shooting Fx，CC0，来源 https://opengameart.org/content/warped-shooting-fx 。使用包内 Hits-2 的 7 张 32×32 PNG，未修改图片，邻近像素放大显示。许可原文位于 `../fx/warped-fx-license.txt`。未使用包内音乐。可选撞击声为 Web Audio 临时合成预览音，并非素材包音频。

## 怎么全掉了（待用户视觉校验）

- `mano-phone.png`：粉色手机壳、深色屏幕的手机道具。
- `mano-keys.png`：两把银色钥匙与粉色爱心挂件。
- `mano-scatter.png`：电子烟、手机、钥匙散落的独立技能图，用于技能格。
- 生成方式：内置 image_gen。以已确认的果汁盒电子烟为视觉参考，三个资产分别生成，透明背景、粗黑阶梯轮廓、有限色板，不使用品牌标识和文字。手机提示词强调粉壳深屏；钥匙强调两把银色钥匙和爱心挂件；技能图强调三个不重叠的物品以三角构图翻落。
- 实际动画通过三个独立 PNG 依次翻转飞出；复用上一技能的本地 CC0 命中特效。
- 350/800/1250ms 分别飞出，950/1400/1850ms 命中，独立扣 9 HP，演示血量依次为 100→91→82→73。2.8 秒结束，算一次行动。
- 累计命中由演出时间决定，跳帧和加速不漏伤害；暂停不重复扣血；技能间切换会重置独立预览。
- 仅验证演出，正式战斗的命中率、随机伤害、AI 和赛制均未接入。

## 抽一口（待用户视觉校验）

- `mano-heal.png`：Mano 将果汁盒电子烟举到嘴边的独立透明像素动作；同时作为技能格缩略图。
- 采用内置 image_gen，以原三版对照图中间的 Mano 50% 版和已确认的果汁盒电子烟为参考。最终提示词要求粉色低双马尾、深色发根、白裙、短躯干短腿；站立举烟、闭眼轻抽；道具不超过头部约 1/4 高。无背景、地板、投影、光晕、文字；烟雾不烘焙进动作图。
- 0–350ms 报招；350–1500ms 举烟抽一口；900–2300ms 复用本地 CC0 星芒并呈现绿色；1500–1900ms 血条从 60 增至 78，浮出绿色 `+18`；2300ms 后归位，2800ms 结束。
- 预览固定从 60 HP 起，恢复 18 HP，不伤害对手。切换技能或重置会恢复独立样板初始状态。并非正式战斗状态。
- 复用的现成星芒是 `../fx/hits-2-*.png`，仅在页面用色相变换调整显示颜色，不改原 PNG。可选提示音为 Web Audio 临时合成预览声。
